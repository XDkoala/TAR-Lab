6. 创建空白 .env，权限为仅当前用户可读写；Git 已忽略此文件。没有读取或复制其他应用的模型密钥。

四、还需要完成的一次性安装
更新：本节安装现已完成，无需再次执行。保留以下内容供以后重装参考。
打开你自己的 Ubuntu 终端，复制以下一行：

bash /home/xd/Documents/Codex/2026-11-16/new-chat/outputs/setup-docker.sh

这个脚本会：
- 用 Ubuntu 软件源安装 docker.io（如已安装则跳过）。
- 启动 Docker 服务。
- 按项目官方 Dockerfile 构建 Agent 镜像，并验证镜像内工具。
- 成功后将你加入 docker 组，让后续运行无需 sudo。docker 组拥有较高系统权限。

sudo 提示时输入的是你电脑的管理员密码，不是模型 API 密钥；终端不显示密码字符是正常的。
不要把密码发到聊天里。首次构建需要从多个站点下载组件，可能比较久。
脚本尚未实际执行：当前助手终端的 sudo 需要密码，因此 Docker 安装和镜像构建结果尚未验证。
脚本不会启动科研任务。构建失败时保留报错，再根据实际原因处理。
如果脚本提示已加入 docker 组，请注销 Ubuntu 后重新登录，使组权限生效。

六、日常使用
以下命令可以在任意目录执行，不需要手动激活虚拟环境。

检查环境：
bash /home/xd/Documents/Codex/2026-11-16/new-chat/outputs/agsci-local.sh doctor examples/circpack

只预览，不花模型调用费用：
bash /home/xd/Documents/Codex/2026-11-16/new-chat/outputs/agsci-local.sh run examples/circpack --dry-run

打开结果查看界面（尚无实际实验结果时列表为空）：
bash /home/xd/Documents/Codex/2026-11-16/new-chat/outputs/agsci-local.sh inspect start --no-build
浏览器地址：http://127.0.0.1:8765
终端按 Ctrl+C 停止网页服务。

Docker 与凭证都准备好以后，以下命令用于默认 Claude Agent 的缩小工作量真实试跑（Codex 需增加 agent.name=codex）：
bash /home/xd/Documents/Codex/2026-11-16/new-chat/outputs/agsci-local.sh run examples/circpack investigation.execution.max_idea_cycles=2 ablations.execution.num_replications=1 ablations.execution.max_evals_per_variant=2 posthoc.execution.max_selected_analyses=1

真实试跑会调用模型，消耗订阅额度或按 API 计费，取决于配置。上述次数只减少工作量，不是硬性费用上限。
CPU 入门任务无需 GPU，也无需预先下载大模型权重。
实验输出位于项目 results/circpack/claude/<run_id>/，论文成功生成时位于 paper/paper.pdf。

七、二次开发从哪里看
examples/：任务说明、初始程序、评估器。建议先复制 circpack，再改成自己的任务。
configs/：模型、实验次数、超时和阶段配置。
src/investigation/：研究与实验迭代逻辑。
src/pipeline/、src/orchestrator/：工作流编排。
src/prompts/、src/agents/：提示词与 Agent 支持资源。
tests/：已有测试。

提交自己的修改前，先在项目目录运行 git status，确认没有包含密钥或实验输出。
未来建立自己的 Fork 后，将它添加为 origin；upstream 继续保留为官方仓库。
不要为了更新而直接覆盖当前目录。先保存自己的改动，再 git fetch upstream 并检查差异。
